# MemoryGameJS

## Description
MemoryGameJS is an interactive browser-based memory game built with JavaScript. Players flip cards to reveal icons, aiming to find all the matching pairs with as few moves as possible. It’s a fun and simple way to test and improve memory skills.

## Features
- Classic card-matching game mechanics
- Simple, user-friendly interface
- Responsive design for desktop and mobile
- Easily customizable icons and themes

## How to Play
1. Click any card to flip it and reveal the icon.
2. Flip another card to try to find its match.
3. If the cards match, they stay revealed; if not, they turn back over.
4. Continue until all pairs are matched.
5. Challenge yourself to solve the game with the least number of tries!

## Installation

To run the game locally:

1. Clone this repository:
   ```
   git clone https://github.com/sastikamd/MemoryGameJS.git
   ```
2. Navigate to the project folder.
3. Open the `index.html` file in your web browser.

## Usage

- Open `index.html` to play the default version.
- To customize cards or themes, edit the corresponding JavaScript and CSS files.
